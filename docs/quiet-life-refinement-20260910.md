# 安静日常与物件细节 · 2026-09-10

仅本地修改与验证，未推送、部署或上传 R2。房间布局、太阳、天气、访客占位、猫控制器保留。

## 自动坐姿动作

删除人物面板中的“看看手机”和“捧杯休息”按钮。坐着的访客自动看手机或捧杯；沿用上一轮保留原手掌的姿态，不重新拉扯袖口和手指来伪造完整举杯动画。主理人继续使用现有日常行为调度。

- 当前画面同一时间最多一位访客做道具动作。
- 新入座或重新进入可见范围后先等 12～22 秒，首屏不早于 14 秒。
- 每次动作 7～12 秒，之后间隔 20～60 秒。出现时间由实际活跃时间累积，后台不追赶时间。
- 首次看手机概率 55%；后续偏向上次未做的动作，同一种动作最多连续两次。多人时优先换一位角色。
- 随机种子复用现有服务器会话种子；生活模块不可用时有本地种子作为后备。
- 走路、躺下、打招呼或离开可见范围时收起道具。作品弹窗及操作面板打开时暂停计时；减少动态模式不触发道具动作。
- 小屋有主要事件时延后新的坐姿动作；后续异步模型加载只更新实例，不清掉已有动作。
- 旧版本的服务端手势接口保留兼容性；当前客户端的手机/咖啡动作不需要请求该接口。

## 新物件与互动

| 物件 | 建模细节 | 互动 |
| --- | --- | --- |
| 书桌压叶手记 | 有厚度的布面封皮、书脊铰接、分层纸页、内衬、书签、压叶和自绘草图 | 点击打开/合上，完整打开后发现“手记里的叶子” |
| 抽屉明信片 | 纸张厚度、轻卷边、自绘建筑小稿和邮票，摆在旧纸张上方 | 打开收藏抽屉，发现“未寄出的明信片” |
| 咖啡台铃 | 拉丝黄铜罩、深绿底座、橡胶垫和独立按键 | 按键轻微回弹，8 秒防重复；咖啡厅的主理人空闲时回应，忙碌时保留简短气泡 |

新发现接入原收藏册，沿用带版本号的本地记录、1.5 秒通知和去重。台铃不会自动创建或启动音频环境：仅在声音已开启且运行时发声，按镜头距离衰减。手记和台铃没有大型弹窗。物件互动会推迟下一个自动环境事件，不截断正在飞行的小鸟。

## 材质

- 木地板、木柜、墙面和织物新增独立的细微粗糙度变化，颜色图与数据贴图分开。
- 圈绒有不完全规则的纤维纹路，水洗棉用更细、低对比的经纬纹；减小圈绒凹凸。
- 咖啡机金属与台铃增加拉丝凹凸及粗糙度；皮革法线强度从 0.30 降为 0.16。
- 石质台面的凹凸贴图改为非颜色数据，凹凸从 0.004 降为 0.0015。
- 新纹理在本地用画布生成，表面纹理 512×512，手记/明信片插画 384×512；没有新增外部下载或 GLB。上一轮人物及动物资源大小不变。

## 验证

构建、TypeScript、修改文件的 lint 和差异空白检查通过。

`check-seated-idle.mjs` 模拟 12 位访客、20 分钟活跃时间，记录 25 次动作：一次最多一个、随机种子可重现、换种子产生不同顺序、冷却范围正确、后入座有等待、主要事件期间推迟、面板暂停、行走/躺下清除道具、减少动态不触发、不补播后台时间。

现有家具几何、猫步态、人物同高和 20 组手机方向、32 座位安全移动、咖啡冷却、生活事件互斥及安全导航检查通过。

真实本地浏览器确认自动看手机、人物面板无手动按钮、面板暂停、手记开合、收藏册重看、台铃冷却、未开声音时静音；没有页面错误。通过近景检查修正了手记底面高度及明信片被旧纸张遮挡的问题。

本机 Chrome，咖啡厅两位访客、每组 4 秒自然场景采样（本段采样时道具动作尚未开始，自动动作另做功能检查）：

| 视口 | 实际绘制 FPS | 帧间隔 P95 | 页面错误 / 横向溢出 |
| --- | ---: | ---: | --- |
| 桌面 1440×1000 | 60 | 16.8 ms | 无 / 无 |
| 手机尺寸与触屏模拟 390×844，DPR 2 | 60 | 16.8 ms | 无 / 无 |
| 手机尺寸、减少动态 | 60 | 16.7 ms | 无 / 无 |

这是桌面设备的浏览器模拟，不是实体手机跑分或满员压力测试。两位访客的四份加载请求均成功。减少动态模式的坐姿动作时钟保持为零。

后台分支另在浏览器显式发送可见性信号验证：隐藏 1 秒期间绘制帧号及两个新计时器均不变，恢复 150 ms 只前进约 150 ms。自动化环境没有可靠地把切换标签页反映为隐藏，因此该项为可见性分支测试，未冒充原生标签页切换测试。

本地截图、性能及互动脚本：`output/playwright/quiet-*`。

## 修改入口

- `app/seated-idle.ts`：坐姿随机调度；`scripts/check-seated-idle.mjs`：行为回归检查。
- `app/seat-scene.ts`、`app/visitor-props.ts`、`app/visitor-seats.tsx`：调度接入与移除手动按钮。
- `app/quiet-objects.ts`：手记、明信片、台铃的模型、材质、互动、声音与收藏。
- `app/house-finishes.ts`、`app/cafe-room.ts`：表面纹理和材质。
- `app/house-data.ts`、`app/room-data.ts`、`app/page.tsx`：物件目录、房间归属与入口。
- `app/room-scene.ts`、`app/life-scene.ts`：复用已有帧循环和生活事件。
- `app/life-data.ts`：两张新发现卡。

后续加小物件可沿用 `quiet-objects` 的独立分组、现有物件目录和收藏接口；角色的新坐姿动作在 `SeatedIdle` 中增加候选类型，并在 `visitor-props` 中配置与原掌心匹配的道具。
