# 全屋材质更新 · 2026-09-14

针对家具材质平、绿色座椅重复的问题，重新搭配全屋木材、布料、皮革、石材、陶器和金属。

| 空间 | 搭配 |
| --- | --- |
| 书房 | 暖亚麻沙发、干邑棕阅读椅、灰棕皮工作椅、羊毛地毯 |
| 客厅 | 奶油圈绒、陶土绒布靠垫、洞石茶几 |
| 卧室 | 雾蓝棉质床品、暖灰羊毛毯、棕皮床尾凳、米色圈绒椅 |
| 咖啡厅 | 焦糖皮卡座、烟草棕皮休闲椅、亚麻餐椅、暖灰柜体与洞石操作台 |
| 藏书室 | 酒红皮阅读椅、米色羊毛窗边坐垫、灰色旧式纹样地毯 |
| 酒吧 | 灰蓝绒布卡座、棕皮高凳、暖灰纹样地毯 |
| 游戏房 | 灰蓝羊毛沙发与坐凳、陶土靠垫 |
| 植物园 | 自然藤编、米色亚麻、陶土与灰蓝靠垫 |

`house-finishes.ts` 为每种表面生成独立的颜色、凹凸、粗糙度贴图，贴图按场景缓存复用；颜色贴图采用 sRGB，凹凸和粗糙度保持非颜色数据。木作纹理随构件长轴分布，地板维持每房间五组网格。独立的织物光泽、皮革高光、陶器釉层与拉丝金属提供不同的光照响应。

反射环境在本地生成一次，强度随自然光和总灯开关过渡，资源随场景释放。皮革阅读椅与书房软垫保留原坐面形状，变形后的平滑法线通过解析变换计算，消除非索引几何重新计算法线产生的块状高光。

默认配色与内置切换选项统一来自 `interior-palette.ts`。用户保存的十六进制自定义颜色继续原样使用。卧室预设搭配独立的羊毛毯颜色，自定义床品则保持原先的派生颜色逻辑。线上发布前只读核对的六项配色均为默认索引 0，因此部署后会显示新默认配色。
