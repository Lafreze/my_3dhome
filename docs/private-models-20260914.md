# 私密模型、压缩与 R2 · 2026-09-14

上传表单新增「私密分享 / 公开展示」选项，默认私密。私密模型不进入公开 `/api/models` 列表；管理员通过已登录的 `/api/admin/models` 管理全部模型。每次私密上传生成 32 字节随机代码，独立页面为 `/models/private/<code>`。这是持有链接即可观看的分享模式，不要求收件人登录。

独立页面只加载这一件模型，不加载公开展柜或其他私密项目；保留旋转、缩放、平移、复位、缓慢旋转、键盘及手机操作。管理员可复制地址、打开独立页面或更换链接。更换后，旧地址的元数据与文件接口均立即返回 404；已经下载到访客设备的数据无法远程收回。

私密文件的原 ID 路由仅允许管理员读取，匿名访问返回 404。分享地址拥有对应单件模型的读取权限，不返回其他项目、R2 对象路径或凭证。页面和接口使用 `noindex, nofollow, noarchive`、`no-referrer`、`no-store`。上传与更换链接沿用管理会话、同源检查和 CSRF 验证。

## 智能压缩

默认勾选，可关闭。处理在独立工作线程执行，不阻塞主服务器；每次只处理一个上传，最多 90 秒。使用 glTF Transform / Draco 高精度几何压缩，颜色与发光贴图使用 WebP，法线、粗糙度等数据贴图使用无损 WebP，贴图最大 2K；不减少三角面。不认识的扩展不强行转换，已较小的 Draco / Meshopt 模型不重复量化。仅保存比原文件更小且重新验证有效的结果，否则保存原文件并明确提示。

实测用户提供的圣翼机甲：66,423,720 → 12,126,040 字节，减少 81.7%；处理约 4.1 秒；处理前后均为 1,983,388 个三角面。上传页显示原始大小、保存大小及实际处理结果。自动测试也验证了动画通道、材质和三角面保留。

参考：[glTF Transform 官方用法](https://gltf-transform.dev/)。

## R2 存储与已有模型

继续使用既有 `kuro-assets` 桶。仅通过 `scripts/upload-exhibit-models.mjs` 上传这三件机甲的六个网页版本到 `kuro/models/exhibits/`，逐件远程 GET 并比较 SHA-256；没有上传其他图片、全局远端清单或无关模型。它们由主站原有模型地址从 R2 读取，无需新域名、公开桶、Worker 或 DNS 更改。

用户后续上传的模型保存到 `kuro/model-library/<独立随机对象名>.bin`。使用 AES-256-GCM 加密；对象名独立于分享代码，R2 metadata 不包含标题、说明或分享链接。即使将来给同一个桶启用公共静态资源域名，上传文件仍是密文，需要现有服务器校验权限并解密。主站文件响应带 `X-Model-Storage: r2`，支持 GLB GET / HEAD / Range。

Railway 数据卷保留藏品目录、可见性和分享代码；新上传的模型文件本体进入 R2。若已有本地上传，启动时逐件复制到 R2，确认成功后原子更新目录，保留原始本地文件。上传失败不发布条目；目录写入失败时可能留下无引用的加密对象，本次没有提供或执行远端删除。原下载文件和旧站点资源均保留。

生产环境新增 `MODEL_STORAGE=r2`、`MODEL_ENCRYPTION_KEY`，并配置既有 R2 账户 / 桶 / 上传凭证；这些值只在服务器使用，绝不使用 `VITE_` 前缀。密钥备份位于 git-ignored、0600 的 `.env.models.local`；既有 R2 凭证在 `.env.r2.local`。必须同时保留加密密钥和 `/data/model-library/catalog.json`，换部署时不能随意生成新密钥。`scripts/configure-model-storage.mjs` 复用已有生产密钥，并跳过自动部署后再整体发布。

现有 R2 凭证的原始登记到期时间为 **2026-10-09**，见 `r2-assets-deployment.md`。应在到期前续期或换新，并同步 Railway 的 R2 环境变量；不要更换模型加密密钥。S3 连接与真实读写已验证。

本地不设置 `MODEL_STORAGE` 时继续保存到本机，可使用 `npm run build` 后 `npm start`。若需本地连 R2，使用两个私密环境文件并指定隔离数据目录。生产配置缺失时拒绝静默切回磁盘。

参考：[Cloudflare 临时凭证与前缀权限](https://developers.cloudflare.com/r2/api/s3/temporary-credentials/)。
