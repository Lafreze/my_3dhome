# 角色坐姿、镜头遮挡与共享便签 · 2026-09-11

## 角色与座位

主理人的原始 GLB 没有骨骼。旧版把裤腰和大腿一起转动，入座后腰身被压缩。本次在加载时生成专用坐姿形变：腿沿连续中心线弯曲，保留横截面和裤管体积；腰身、领口和插兜的手保持原形。11 根轻量骨骼只承担小幅日常动作。异步模型替换直接采用角色当前姿态，不再闪现站在椅子上的一帧。

五位访客保留原始站立与躺卧造型，坐姿小幅向前留出靠背余量；栗栗、银铃的鞋尖轻微朝下，绯狐的长袖下摆稍向前垂。六个人物仍统一为 1.3 场景单位站立高度。修复 UV / 材质分片间的细小法线接缝，统一适度粗糙的布料和皮肤反光，不改原始颜色，也不再增加手臂变形。

客厅沙发的入座点前移 0.24 场景单位，咖啡厅卡座前移 0.18，让短腿的膝盖越过坐垫前沿。茶几向电视方向移动 0.30，保留原房间和家具组合，并给沙发前方留下可通行距离。

导航生成器禁止从沙发靠背方向进入，重新生成全部 32 座位 / 496 组安全路径。主理人与访客复用相同的座位通道。起身先向坐垫开放侧移动再伸腿；入座逆向进行。主理人的实际身体位置参与占位检查，过渡期间不会把身体碰撞位置固定在旧节点。不会站在坐垫上再走下来。

## 镜头遮挡

`camera-occlusion.ts` 检查镜头至观察目标之间的家具包围盒，隐藏遮挡物的可见网格。电视、显示器、柜体等可以自动让开视线，离开遮挡后恢复；180 ms 保留时间避免边界闪烁。座位锚点和导航碰撞体始终存在。被主动查看的物件不隐藏，窗墙继续使用原有剖面规则。电视原生网页层跟随屏幕网格可见性。

## 共享便签

五个房间各有一张可点击便签，也可以从“探索”找到。书房便签靠桌后侧，客厅便签放在书上，卧室放在床头柜，展厅便签贴墙，咖啡厅便签放共享桌。纸张保留薄厚和轻微翘角，书桌上的纸张随桌面遮挡一起隐藏。

- 访客可署名或匿名留言，正文最多 240 字，署名最多 16 字。
- 留言按房间查看，打开界面后每 15 秒更新；后台停止轮询。
- `GET /api/notes` 公开读取，`POST /api/notes` 公开新增；正文以纯文本渲染。
- `DELETE /api/notes` 必须通过现有管理员会话、同源和 CSRF 检查。普通访客连自己写的留言也不能删除。管理界面有删除确认。
- 每 IP 至少间隔 30 秒，10 分钟最多 5 次提交；每房间 200 张、全屋 1000 张上限，满额不自动删除旧留言。
- 数据以版本化 JSON 原子写入既有 Railway 持久卷 `/data/room-notes.json`。不占用作品设置，也不需要新服务。

管理员入口仍是电脑网址栏中的既有暗号机制；不在角色或便签上增加暗号提示。
