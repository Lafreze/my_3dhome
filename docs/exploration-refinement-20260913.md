# 漫游拾光 · 2026-09-13

本轮在十个房间各加入一件可近看、可操作的小机关，延续木作、黄铜、纸张、陶器与低饱和配色。所有模型和插画均由项目内代码生成，不增加外部素材请求或大型模型下载。

探索菜单显示当前房间的一条线索；收藏册新增「漫游拾光」，提供独立线描、10 项进度、未发现线索与已发现故事。物件动作完成后才记录发现，重复操作不会重复授予，物件卡可继续前往下一处。收藏保存在当前浏览器，兼容原有收藏数据；存储失败时仍保留本次访问的结果并给出提示。

动作只使用场景时间。打开弹窗、切换房间或隐藏页面时暂停，不会在后台跳过过程。减少动态模式直接呈现动作结果。声音在亲手操作后启用，为本地合成短音；离开后台会清理正在发声的节点，销毁场景时释放音频上下文。

近看视角优先于房间通用视角，藏书室、酒吧、游戏房、花园中的小物也能贴近查看。修正床头眼镜盒与音乐盒的间距；磨豆机避开拉花工具，风铃避开墙画，陀螺避开奖杯，纸风车避开浇水壶。静态部件按父分组和材质合并；所有运动部件、玻璃与独立画页保留各自结构。
