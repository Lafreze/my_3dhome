# 展厅与藏品管理 · 2026-09-14

线上展台为空时，模型资源接口返回 503。相同 R2 文件使用新凭证读取正常；问题来自一小时临时凭证缺少 SDK 所需的 `expiration`，长时间运行的客户端持续使用过期凭证。

本次修改将到期时间交给 SDK 自动刷新。三个内置展品的六个资源保留 R2 为首选来源，读取失败或字节校验不符时，可使用部署内完全相同、经 SHA-256 校验的备用文件。备用路径只允许内置展品，不接触上传的私密文件。

展柜改为独立制作的书册、陶器和金属环摆件，实际机甲仅装载在三个展台。保留展柜进入藏品室的操作和既有通道位置。

管理员可在藏品室选择上传的模型，再点击“删除模型”。服务端校验管理员会话、同源请求和 CSRF。先持久化删除状态以撤销公开、管理及分享地址，再删除对应的 R2 加密对象和旧本地副本；存储异常时保留撤销状态并自动重试，重启后继续清理。内置展品没有删除入口。

新增四幅内置 imagegen 画作，源文件与完整提示词见 [画作说明](interior-art-20260914.md)。书房和咖啡区采用三联画，客厅和卧室采用双联画，画面连续且各画框独立；展示区副画、连廊八幅画、酒吧、藏书室和游戏房挂画改为生成作品。保留管理员此前指定的挂画配置。画作按房间加载，同一作品共用图片源，裁切维持原始比例。

验证：67 项自动检查通过，覆盖 200 MB 上传、存储加密、管理权限、分享撤销、删除中途读取、失败后恢复、R2 凭证续期、备用文件完整性、模型密度、通道布局和既有游戏。生产构建及类型、代码检查通过。浏览器验证三个展台加载完成，逐房间检查挂画，并完成本地临时模型的上传、取消删除、确认删除和地址失效检查。线上已有模型未被删除。
