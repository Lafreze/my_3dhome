# 漫游与白凛验收 · 2026-09-16

## 实现

- 电脑端按主要指针类型隐藏触屏摇杆和星形按钮，窄窗口也不会误判为手机。删除常驻按键说明、空闲提示和进入漫游的说明弹条，只在有互动目标时出现「E · 物件」。
- 镜头保持固定方向、平滑跟随。滚轮、触控板/双指缩放、加减按钮与键盘加减键控制距离；限定近远范围并记住距离。关闭物件面板保留距离，明确点击重置视角才恢复默认距离。
- 方向键/WASD 行走、Shift 快走；摇杆轻推慢走、推到边缘快走。起步缓动、松开即停，碰撞处仍可转身面向物品。自由行走步幅与阴影更新同步。
- 互动优先面前目标，校正房间原点上的窗户和两盏床头灯的实际互动位置。打开面板暂停，关闭继续。衣橱保存后更新当前漫游角色。
- 操作取向参考任天堂《动物森友会》的方向移动、快走和统一情境动作理念，适配网页键鼠与触屏输入：[官方操作说明](https://csassets.nintendo.com/noaext/image/private/t_KA_PDF/3DS_Animal_Crossing_New_Leaf_en?_a=DATAg1AAZAA0)。

## 新角色

- 角色 ID `ivory`，衣橱名「白凛」；来源为用户提供的 `hi3d-white-boy_1.glb`，原文件保持不变。
- 200 万三角面简化为 47,999 面，每姿态约 1.61 MB，原始 PBR 贴图缩为 1024 像素。坐姿和完整站姿分别导出，行走使用对应 UV 的站姿数据，躺姿对完整站姿做整体变换。
- 已注册衣橱、配色、身高、落脚点、眼睑/呼吸、座位与床上休息配置；沿用现有应用资源分发方式。
- 可用 `scripts/prepare-guest-figures.py -- ivory <源文件>` 在 Blender 后台生成，再运行 `scripts/register-guest-profiles.py` 注册测量配置。源文件摘要和模型边界保存在 `public/models/visitor-ivory.json`。
