# 游戏厅与模型上传精修 · 2026-09-14

本次范围：单模型上限 200 MiB、精简模型页面说明、九款可玩街机/主机游戏、模型表面与结构细化。沿用现有 kuro.cafe、Git 仓库及 Railway 服务。

## 上传和私密模型

- 前后端上限均为 200 MiB（页面延续 MB 标注）。浏览器每段最多 10 MiB，失败分段自动重试；服务器校验顺序、长度与重复分段哈希，按编号重组。
- 管理员会话和 CSRF 保护创建、传输及提交；进度只对发起上传的管理员会话可见。临时片段位于网站目录之外，目录 0700、文件 0600；完成后移除，过期任务在后续操作及启动时清理。
- 压缩和 R2 保存作为后台任务处理，浏览器轮询进度，避免把整个压缩过程挂在单次 HTTP 请求中。已开始的任务不会因关闭浏览器而中断。
- 压缩保留原有面数、材质与动画；工作线程限制 768 MiB JS 堆和 180 秒，不能压缩时回退原文件。减少接收、解码及加密过程中的整文件拷贝。
- 继续使用已有加密 R2 对象存储和随机分享地址；公开列表不包含私密上传。没有更改加密密钥或已有私密链接。
- 移除私密页口号、公开藏品页闲述与多余上传说明，保留模型名称、作者说明、操作控件和必要错误提示。
- 网关背景：[Cloudflare 上传限制](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/4xx-client-error/error-413/) 会因套餐限制单次请求大小，分段请求避免 200 MiB 整体请求被拦截。

## 模型精修

- 三件机甲从用户原始模型分别生成展示和近看版本，原文件未改动。房间版本从 45,000 增至 90,000 三角面；近看版本从 160,000 增至 300,000。两档各自从原始几何生成，避免逐级简化损伤轮廓。
- 提高位置/法线/UV 编码精度。房间文件约 0.87–0.97 MiB，近看文件约 2.29–2.57 MiB；六件 R2 新对象上传后已逐一验证 SHA-256。
- 全屋黄铜增加细密拉丝反射、织物增加柔和绒面反光；补充客厅/卧室/书桌缝线。
- 游戏厅细化大圆角、金属件、投币门螺丝、控制面板、主机散热槽、手柄肩键/摇杆环、沙发包边。静态细节合并绘制，原家具占地、门和通道未扩大。
