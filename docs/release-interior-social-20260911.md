# 室内整理、轻量动作与访客互动 · 2026-09-11

本次按用户要求发布到既有 kuro.cafe / Railway my-3dhome，包含前几轮保留在本地的角色、衣柜和生活细节。此前文档中“仅本地”的说明记录当时状态，发布后的行为以本文件为准。

## 本次修正

- 房门使用门楣内的隐藏轨道，移除向卧室两侧伸出的横杆；保留门扇开合和既有通行位置。
- 床上保留一整块规整被套和适度褶皱，去掉独立翻角碎片，左右下垂恢复对称。衣物篮仍保留衣物。
- 桌面肖像移到后方书柜顶层，工作区域留给键盘、鼠标和相机。
- 四个咖啡储存罐整组移到后操作台的托盘内，底部接触托盘，不跨越水槽或台面边缘。
- 访客坐姿起身 0.7 秒、入座 0.8 秒，躺卧起身 1.15 秒、躺下 1.25 秒。步行速度由 0.72 调到 0.96 场景单位/秒，接近座位由 0.46 调到 0.68。沿原安全路线移动。行程包含速度，旧行程继续使用旧值，避免更新时发生位置跳变。
- 行走只做很小的腿部步幅和抬脚；主理人减少大腿旋转并取消步行膝盖弯折。手机与杯子在身前悬浮，手机屏幕朝向眼睛，手臂不参与道具动画。看手机与喝咖啡仍由自动坐姿调度触发。

## 用户间互动

点击同房间访客，增加“请喝咖啡”“为你鼓掌”“说声谢谢”。发送者和接收者显示各自文案的短气泡，不替对方切换姿势或移动位置。原有点头、心意和四种表情保留；外观仍只能通过衣柜修改。

| 项目 | 规则 |
| --- | --- |
| 气泡时长 | 9 秒，覆盖访客轮询间隔 |
| 发送者冷却 | 8 秒 |
| 接收者冷却 | 4 秒，避免多人同时刷屏 |
| 地点 | 双方在同一房间 |
| 姿态 | 走路和躺卧期间不可触发 |
| 数据 | 服务端使用已有访客身份与连接；客户端不能伪造对方动作 |

实现入口：`app/visitor-social.json` 配置文案与颜色，`visitor-expression.ts` 绘制气泡，`seat-scene.ts` 展示与状态同步，`visitor-seats.tsx` 提供操作，`scripts/seat-presence.mjs` 校验对象、姿态和冷却。Docker 运行镜像包含新的社交与表情配置。
