# 衣柜入口、角色表情与生活细节 · 2026-09-10

本轮仅本地修改，没有推送、部署或上传 R2。保留已有布局、黄昏阳光、天气、小猫、访客安全移动及随机坐姿动作。

## 角色入口

- 只有卧室的木作衣柜提供人物、昵称和颜色编辑；物件目录中的衣柜入口也会定位到衣柜。
- 第一次点空座位直接放置角色；再次点角色只显示位置、当前状态与互动，没有外观编辑字段。看手机和捧杯继续由既有随机调度触发。
- 衣柜保存使用独立的 `appearance` 操作，只更新当前访客自己的外观，不更换座位、不重置躺卧姿势。行走尚未结束时禁止修改。
- 未入座时可以先在衣柜保存本地造型，之后放置时使用。
- 增加开心、好奇、灵感、困困四种表情气泡。通过原访客接口向其他访客同步，2.5 秒防重复，6.5 秒收起，不能替其他访客发送自己的表情。复用轻量画布，不拉扯没有面部骨骼的 GLB。

## 第一批模型与小装置

| 位置 | 内容 | 动作与支撑关系 |
| --- | --- | --- |
| 书桌 | 鼠尾草绿风扇、镜头盖、金属眼镜、整理过的短线缆 | 风扇底座、支架、网罩、扇叶和机头分开；叶片转动，机头约 30 秒左右摇一轮，点击开关；相框移到右侧留出间距 |
| 书柜 | 不同高矮的书、倾斜书与书挡、书签、横叠书、半开的布面盒 | 书挡接住倾斜书，盒子有内壁和真实后侧铰接的盖子 |
| 书房与客厅唱片机 | 共用唱臂机械动作 | 先移臂再落针；播放时约 33⅓ RPM，唱臂缓慢向内；停止先抬针再回位，中途停止也不会向下跳 |
| 咖啡厅后墙 | 木作机械摆钟 | 放在植物层板下方留白中；钟壳、指针、钟摆独立，指针按当前时间运行，无自动滴答声 |
| 咖啡操作台 | 金属奶缸、压粉器、敲渣桶、托垫、搭到台边的抹布 | 奶缸与桶有厚度和内部空间，敲渣杆两端接桶壁，抹布在台沿转折 |
| 咖啡杯组 | 奶油白、灰绿、灰蓝杯具；不同杯柄朝向；软木杯垫 | 层板陈列适当留空；杯碟接触垫子，保留空桌和已有蒸汽 |
| 床与衣篮 | 不对称垂落的被套、一角翻开、错开的枕头、空心衣篮、提手和搭出的布料 | 不添加空床持续呼吸；衣物跨过篮口并下垂 |
| 床头柜 | 眼镜盒、水杯、充电座和短线缆 | 用品集中在现有台面边缘，保留原台灯与书 |
| 扫地机器人 | 轮轴、侧刷、机身饰圈、指示灯、完整充电座和接触片 | 轮子随实际路程转动，侧刷仅移动时旋转；复用安全路线和避让，电量至少恢复至 90% 后才再次出发 |

固定零件按材质合并，运动零件保留各自真实转轴。风扇和钟摆只在所属房间或整屋视角更新；面板打开时暂停，后台停止；减少动态时取消旋转和摆动。没有新增模型下载或骨骼动画。首帧时间差增加非负保护，防止初始化较慢时计时倒退。

## 验证

- 构建、TypeScript、修改文件 lint、差异空白检查通过。
- 新增服务端检查：外观只能改自己、无效参数不部分写入、保持座位与休息姿势、行走期间拒绝修改；表情同步、冷却、过期与禁止操控他人。
- 新增机械检查：落针与回位顺序、提前停止、缓慢向内移动、减少动态静止；布料坐标有效；低电量机器人返回充电座并充足后再离开。
- 现有家具、自动坐姿、猫步态、人物统一 1.3 场景单位高度、20 组手机方向和五种访客的休息姿态检查通过。
- 真实浏览器验证首次直接入座、衣柜保存、座位保留、点击角色无编辑字段、发送表情、风扇开关、钟摆运行和弹窗暂停。近景检查修正了相框与风扇重叠、摆钟被层板遮挡和布料碰到篮沿。

本机 Chrome，每个房间 4 秒绘制帧采样，咖啡厅包含两位访客：

| 视口 | 书房绘制 FPS / 帧间隔 P95 | 咖啡厅绘制 FPS / 帧间隔 P95 |
| --- | --- | --- |
| 桌面 1440×1000 | 60 / 16.8 ms | 60 / 16.8 ms |
| 手机尺寸与触屏模拟 390×844、DPR 2 | 60 / 16.8 ms | 60 / 17.2 ms |
| 手机尺寸、减少动态 | 60 / 16.8 ms | 60 / 16.8 ms |

没有页面错误或横向溢出；减少动态模式下风扇与钟摆计时保持为零。后台项通过显式触发 Page Visibility 分支验证，隐藏期间绘制帧号与装置状态均不变。这是桌面浏览器的手机模拟，不是实体手机或满员测试。

手机衣柜另做实际操作检查：390×844 视口中面板完整显示，人物下拉框、调色板和保存按钮可用；最后构建的首帧装置计时为非负值。
