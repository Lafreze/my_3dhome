# kuro.cafe 室内美术更新

2026-09-09。以用户提供的五张室内效果图为材质、分组和光照参考，保留既有房屋布局与通道，未复制参考图中的全部物件。

## 完成内容

- 咖啡厅先确定鼠尾草绿柜体、暖橡木、奶油白、陶瓷、玻璃和金属标准，再复用至全屋。柜门、桌板、窗框保留厚度和圆角，操作台与餐桌保留空白。
- 全部房间使用交错接缝的暖橡木地板；窗边局部深木格栅；卧室灰蓝床品；展厅统一中性色。
- 家具增加软包轮廓、正确方向的缝边、平面织物 UV、床垫层次、被褥垂边、毯子褶皱和接触阴影。
- 客厅增加唱片机，卧室增加可坐下的阅读椅。全屋 32 个位置（30 座位、2 床位），既有家具和座位 ID 保留。
- 默认晴朗黄昏；现实天气仍可手动启用。自然光、室内灯具、屏幕／柜架弱光分层；夜间降低整体填充光，突出吊灯与展品聚光。
- 轻蒸汽、窗帘／植物微风、晴日微尘、唱片旋转与唱臂缓落、咖啡机工作灯和蒸汽、黑猫随机休息、书房与客厅坐垫轻微下陷。黑猫避开被占用的位置，并随窗墙剖切隐藏。
- 中央、左侧、右侧展位分别映射作品编辑器的第 1、2、3 项，封面与说明卡随编辑更新；点击后聚光、慢转，再打开介绍。减少动态效果模式直接打开介绍并停用环境循环。
- 不再请求默认王冠兔和已被共享材质取代的咖啡厅贴图；保留原始文件、历史优化模型和生产 catalog。

## 内容与兼容范围

尚未收到正式项目截图、描述或链接，初始三项为标明用途的概念封面，不代表真实项目履历。用户已有的个人资料和独立墙画不会被覆盖；新增／排序／删除项目仍使用现有编辑器。空展位点击后进入作品编辑。

原生视频在同源或本地视频可读取像素时，以 2 Hz 采样平均色并平滑照亮电视背墙。YouTube 等受跨域限制的播放器维持中性弱背光，保留原生播放与字幕。

不增加环境音频文件或新外部素材。R2 公开域名与模型分发授权仍属于单独部署步骤；本次沿用既有 Railway 服务的本地资源默认配置。
