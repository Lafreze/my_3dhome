# 小屋管理与共享设置

点击主理人仅出现问候气泡。管理入口放在书房电脑的「电脑网址」输入栏：提交服务器配置的暗号后进入管理模式；访客界面没有暗号提示、独立登录表单或管理按钮。输入错误时只返回普通的网址格式提示，输入值不会进入 iframe、网址或本地存储。当前入口接受不符合 HTTP/HTTPS 网址格式、最多 256 字符的暗号。

验证后右上角显示「管理小屋」，可编辑家具配色、个人资料、作品集、相册、公开随笔、电脑／电视网址，以及客厅和展厅画作。退出后所有编辑入口隐藏；灯光、视角、播放暂停和在线访客仍可正常互动。访客提交普通网址仅在本次访问预览，不写入服务器；只有验证后的保存会共享给所有访客。服务器权限检查独立于入口是否可见。

## 部署设置

- `STUDIO_ADMIN_PASSWORD`：服务器验证的管理暗号。初始值按屋主要求在 Railway 配置；代码和前端资源不包含暗号。更改变量并重新部署后，旧会话失效。
- `STUDIO_PUBLIC_ORIGIN=https://kuro.cafe`：管理请求的允许来源。
- `STUDIO_DATA_DIR=/data`：现有 `my-3dhome` 服务的持久卷挂载目录。

设置保存在 `/data/house-settings.json`，不属于网站公开目录。文件含版本、递增 revision、更新时间以及公开设置；不保存暗号或会话。临时文件写入并同步后原子替换，成功后才更新内存。重新部署或重启会保留设置，管理者需要重新登录。当前设计为一个服务实例；多实例部署前应改用支持事务的共享数据库。

本地运行仍使用 `node scripts/serve-local.mjs`，默认保存到忽略提交的 `output/server-data`。通过本机环境变量设置管理暗号；没有暗号时管理接口关闭，不提供代码内置的默认密码。

## 接口与权限

| 接口 | 用途 |
| --- | --- |
| `GET /api/house` | 所有人读取公开配置；支持 revision ETag 和 304 |
| `POST /api/admin/login` | 验证暗号，创建 8 小时会话 |
| `GET /api/admin/session` | 查询当前登录状态和 CSRF token |
| `POST /api/admin/logout` | 注销当前会话 |
| `PATCH /api/house` | 仅管理者保存经过校验的设置，必须带当前 revision |

会话使用随机令牌和 HttpOnly、SameSite=Strict Cookie，生产环境带 Secure。所有修改检查同源 Origin、会话与 CSRF token。错误暗号按 IP 限制为 15 分钟内 5 次；真实来源只信任 Railway 的有效 X-Real-IP。后台串行保存，过期 revision 返回 409，防止两个管理页面相互覆盖。生产容器仅在启动时准备卷权限，HTTP 服务以 node 用户运行。

访客每 15 秒在前台检查一次更新，切回页面时也会刷新；未改变时返回 304，不重复传送图片。访客不能保存网址、配色、作品或随笔。个人的动物收藏及在线访客外观仍使用原有机制。

## 内容与兼容性

电脑支持 HTTP/HTTPS 网页；电视支持网页、YouTube、MP4/WebM/Ogg 视频直链。服务器保存网址而不抓取远端页面。普通网页 iframe 使用沙箱；网站自身的 CSP、X-Frame-Options 或浏览器混合内容限制仍然有效，可使用「原网页／独立打开」。本地视频只供管理者本机预览，不上传或作为公开播放源。

图片先在浏览器压缩，再随设置保存到服务器。每张最多 500 KB，只接受 PNG/JPEG/WebP，最多 12 件作品、6 张相册和 5 个墙面画框。服务端校验协议、字段、文本长度、配色范围、图片签名和总请求大小。随笔及描述作为普通文本展示，不渲染上传的 HTML。

旧浏览器内容不会自动覆盖服务器。管理者可在个人资料编辑器选择「导入本机旧内容」，检查后点击保存，或使用原有 JSON 导入／导出。原来的浏览器存储没有删除。

## 展台与验证

三个项目展台统一为宽 1、深 1、高 1.02 场景单位；卡牌展台不再是狭长柜体。展品位置保持原样，导航碰撞范围同步更新。

`node --test scripts/check-admin.test.mjs` 覆盖未登录写入、错误暗号、来源／CSRF 拦截、退出、会话过期、限流、输入校验、并发 revision 冲突及重启恢复。`node scripts/check-life.mjs` 覆盖 986 条路径和行为调度；`node scripts/check-house.mjs` 验证房屋通道与电视地址解析。2026-09-10 浏览器复测通过主理人无入口、错误输入无暗示、访客网址零写入、隐藏入口验证、随笔和网址服务器保存、第二访客共享读取、退出隐藏入口，以及暗号不出现在 iframe／localStorage。验证使用独立本地数据目录，没有改写线上内容。浏览器脚本位于本机 `output/playwright/resident-entry-qa.js`。
