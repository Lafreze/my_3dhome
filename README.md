# 小森居 · Komori

一个原创布置的 Three.js 互动小屋，使用 React、Vinext 和 Three.js。所有家具和相框风景均由本地三维几何构建，无需外部模型或图片服务。

## 开始

- 安装依赖：`npm install`
- 本地运行：`npm run dev`
- 生产构建：`npm run build`
- 类型检查：`npx tsc --noEmit`
- 应用检查：`npx oxlint app`

## 互动

拖动旋转，滚轮或双指缩放；点击家具后相机靠近，详情卡提供物件操作。也可使用「探索物件」通过键盘访问所有物件。

- 白昼 / 夜晚：窗景、星月、自然光、屏幕光同步变化。
- 台灯：独立开关；在夜晚形成暖色照明。
- 电脑：可编辑便签，保存在当前浏览器的 localStorage。
- 相框：三幅立体风景；书架：三页原创慢生活手记。
- 床、阅读椅、地毯：切换颜色；木凳：旋转。
- 绿植：浇水动画；咖啡：热气；唱片机：播放 / 暂停 Web Audio 旋律。
- 全景、放大、缩小、全屏、帮助；支持减少动态效果偏好。

## 文件

`app/room-scene.ts` 定义场景、几何、灯光、射线拾取和相机控制；`app/room-data.ts` 为物件内容；`app/page.tsx` 为页面与交互；`app/landscape.tsx` 为相框内容；`app/globals.css` 为响应式样式。

## 验证与限制

已完成生产静态构建、TypeScript 检查与应用源文件 lint。脚手架自带的部分未使用 UI 组件有既有全仓 lint 报告，未改动这些组件。本次没有进行浏览器视觉或点击测试。

WebMCP 在支持 `document.modelContext` 的浏览器中提供 `configure_komori_room`；无支持环境时安全跳过。当前环境未提供可用于合同检查的 WebMCP 上下文，因此未验证这项可选接口。

需要支持 WebGL 的浏览器。便签不会同步到其他设备；音乐由浏览器合成，需用户点击播放。私人部署需要拥有者登录。
