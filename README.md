# SATORI · 四间屋

一个支持本地运行与 Railway 部署、按 2×2 布置的三维个人展示屋：左上书房、右上客厅、左下卧室、右下展示区。原创空间采用橄榄绿、灰泥、木材、亚麻与陶器；家具、绘画和声音由本地代码构建；木材、皮革、织物和灰泥结合了已下载的 CC0 PBR 素材与程序纹理。小屋本身不依赖外部模型、图片、字体或音频服务。仅在用户主动播放在线影片时连接视频服务。素材来源见 `THIRD_PARTY_ASSETS.md`。

## 本地运行

```sh
npm install
npm run build
npm start
```

打开 http://127.0.0.1:3000/ 。服务只监听 `127.0.0.1`。如果端口被其他应用占用，可使用 `KOMORI_PORT=3001 npm start`。

开发模式使用 `npm run dev`，同样只监听本机。

## Railway 部署

代码仓库：https://github.com/Lafreze/my_3dhome

Railway 服务连接此仓库的 `main` 分支。`Dockerfile` 使用 Node.js 24 构建静态页面，运行容器只包含页面、素材和静态服务；不需要数据库或额外密钥。`railway.json` 设置 `/healthz` 健康检查和失败重启。

容器通过 `STUDIO_HOST=0.0.0.0` 接收请求，端口读取 Railway 的 `PORT`。本地直接 `npm start` 仍默认监听 `127.0.0.1:3000`。部署说明参考 [Railway Dockerfile 文档](https://docs.railway.com/builds/dockerfiles)。

本地照片、视频和编辑器保存的个人配置不会随代码部署上传；浏览器存储按域名隔离。若要把本地布置迁移到线上页面，请先在本地导出配置，再到线上页面导入并保存。

## 四个房间与俯瞰

顶部切换书房、客厅、卧室、展示区。底部「整屋」显示同一场景中的四间房；「俯瞰」从正上方查看 2×2 格局，隐藏门洞上方墙体并显示房间标记，点击俯瞰图中的房间即可进入。外墙随观察方向做剖切，保留窗景与完整模型，避免墙壁挡住家具。

- 书房：保留原先的工作台、书架、阅读区和全部互动。
- 客厅：沙发朝向大电视；电视柜分区放置 Switch、游戏主机、音箱和游戏收藏，桌上有无线手柄、遥控器和书杯。
- 卧室：床头软包、枕头、床尾织物、双侧床头柜与灯、衣柜内部挂衣和叠放收纳、床尾长凳与洗衣篮。
- 展示区：与个人作品封面同步的三幅画作、轨道照明、可转动雕塑、可抬起玻璃展罩的收藏柜和观看长凳。

房间中心间距为 8 × 6.8 单位，每单位 0.625 m。四条房间连接门洞宽 1.4 单位，沿各房间主要通道布置。`node scripts/check-house.mjs` 检查四个房间的位置、家具边界、碰撞、主要路线、衣柜开启范围、沙发电视对齐及视频链接解析。

## 电视播放

客厅点击电视，或从「探索」选择「家庭影院」，再点「打开电视」。

- 粘贴 YouTube 视频、短链接、Shorts 或直播链接，按播放；支持链接中的起播时间。
- 可输入 MP4、WebM、Ogg 视频文件直链，也可选择本地文件。普通网页链接不会冒充视频流。
- 本地视频只通过浏览器临时地址读取，不上传；可加载 VTT 字幕。本地视频还同步到 3D 电视屏幕。YouTube 使用原生嵌入播放器在影院面板中播放。
- 关闭电视电源或关闭影院会停止播放并清理播放器；有网络或嵌入权限限制时显示反馈，可用「原网页」打开影片。

YouTube 在线播放受网络、浏览器播放规则与影片嵌入权限影响。接口按照 [YouTube 官方嵌入文档](https://developers.google.com/youtube/iframe_api_reference) 配置，携带当前页面来源，不代理视频。

## 展示与互动

拖动环顾、滚轮或双指缩放。点击物件后镜头靠近，简洁的物件卡提供对应操作；卡片与控制栏跟随实际可视区域，缩放时保持在屏幕内，矮窗口中卡片内部可滚动；「探索」也能通过键盘访问当前房间的物品，整屋模式下可访问全部 38 件物品。

- 作品墙、电脑和工作台：打开作品集，浏览封面、分类、说明及可选作品链接。
- 桌上肖像：个人介绍。相机：最多 6 张本地照片，无照片时展示原创视觉习作。
- 抽屉：有内部结构的滑动开合；雕塑：平滑旋转；工作椅：朝向电脑，前后拉出 / 归位。
- 唱片机：旋转唱片、唱臂起落，以及浏览器合成的原创旋律。
- 咖啡：续杯热气；三处植物：各自响应浇水，窗边植物带细微摆动。
- 沙发、皮革椅、地毯：更换配色。
- 蘑菇灯与折臂工作灯：分别开关。窗景：右上角「时间与天气」，或点击山景窗，选择清晨、午后、黄昏、夜晚，以及晴天、阴天、雨天，合计 12 种组合。日光方向、色温和室内亮度同步过渡；窗外有分层山林、流云、星月，雨天有动态雨丝、玻璃水滴和远山薄雾。设置是手动模拟，不读取现实天气。
- 书架：打开手记，编辑并本地保存随记。

支持全景复位、缩放、桌面全屏、弹窗焦点约束、Esc 关闭及减少动态效果偏好。手机构图会自动适配宽高比；真实设备触摸体验仍以设备浏览器为准。

## 换成自己的内容

右上角调节图标打开编辑器：

1. 修改名称、短标题与个人介绍。
2. 编辑、添加或移除作品，保留 1–12 件；前三件的封面同步到屋内画框和电脑屏幕。初始三件是原创示例，不代表用户真实履历。
3. 上传 JPG、PNG 或 WebP 封面和照片。单张原文件上限 20 MB，上传后在本机缩小到最长边 1000 像素。
4. 点击「保存布置」。内容保存在当前浏览器的 `localStorage`，不会发送到服务器，也不会跨浏览器同步。
5. 导出按钮备份已保存的配置；导入 JSON 后可预览、编辑，再点击保存。

浏览器存储空间有限。如果图片较多导致保存失败，编辑器会明确提示；可以减少图片后重试。清理浏览器数据会删除本地内容，建议先导出备份。作品链接仅支持 HTTP/HTTPS，只有点击后才会访问外部作品。

## 扩展结构

- `app/house-data.ts`：2×2 房间注册、物件所属房间和家具占地。
- `app/house-rooms.ts`：三个新增房间、共享门洞、家具细节、交互动画和电视屏幕。
- `app/television.tsx` 与 `app/video-source.ts`：视频播放、来源解析和资源清理。
- `app/room-data.ts`：个人内容、作品类型、物件注册表和场景 API。
- `app/room-layout.ts`：统一家具占地、朝向、活动行程和主要路线。
- `app/environment-data.ts`：时间、天气选项及类型。
- `app/room-environment.ts`：本地生成的窗景、雨滴动画与光照参数。
- `app/environment-picker.tsx`：时间与天气的简洁控制面板。
- `app/use-visible-viewport.ts`：缩放、窗口和软键盘变化时的可视区域边界。
- `app/room-materials.ts`：本地 PBR 材质加载。
- `app/room-scene.ts`：带物件 ID 的分组、几何、材质、灯光、拾取、相机与动画。
- `app/room-textures.ts`：可复现的木纹、织物、灰泥、皮革及画作、屏幕纹理。
- `app/studio-art.tsx`：作品阅读视图与本地图片预览。
- `app/page.tsx`：极简界面、内容编辑、备份和交互分发。
- `app/globals.css`：昼夜风格、近看状态、桌面和手机布局。
- `scripts/serve-local.mjs`：本地与 Railway 共用的静态服务。

新增物件时，在 `objects` 注册 ID 和文案，在场景中通过 `group(id, x, y, z)` 建模，然后在 `interact` 或页面的 `action` 中连接行为；探索列表会自动包含新物件。增加新的区域可继续使用同一分组方式组合家具，并通过 `RoomApi.focus` 进入区域。作品上限由编辑器与配置验证共同限制，可按需要调整。

## 验证

- `npx tsc --noEmit` 与 `npx oxlint app`。
- `npm run build` 生产静态构建。
- Playwright 桌面与 390 × 844 手机视口视觉检查。
- 原有 20 个物件以及新增 18 个物件的选择、操作和对应弹窗检查；昼夜、抽屉、作品切换、照片上传和刷新后本地保存检查。
- 12 种时间与天气组合检查；320 px 窄屏、280 px 高横屏及 200% / 300% 页面缩放下的物件卡边界检查。
- 本地视频播放、关机停止、关闭清理与 YouTube 嵌入检查。
- 小屋加载与本地视频播放过程无外部资源请求；本地服务监听地址核验为 `127.0.0.1:3000`。

需要支持 WebGL 的浏览器；音乐需主动点击开始。手机检查使用浏览器视口模拟，未在实体手机上验证。Three.js 的生产分块会有体积提示，场景仍通过动态导入加载。

## 布局核验

运行 `node scripts/check-layout.mjs` 会检查：房间边界、家具之间的占地碰撞、椅子朝向、工作椅拉出和抽屉全开的活动范围、书柜前取书区及主要路线余量。结果与俯视图生成在 `output/playwright/`。

场景尺寸约定为每单位 0.625 m。沙发到茶几净距约 41 cm，书柜前取书区深 60 cm，主要路线中心距最近家具约 42 cm。这些是虚拟场景中的布局检查，未作为实体建筑施工规范认证。墙面画作在沙发上方；书柜独立靠后墙；雕塑收在唱片柜上；桌面物件跟随桌子父分组，后续移动书桌时不会遗留悬空物件。
